# ФАБРИКА — автономный контур разработки

ФАБРИКА — изолированная рабочая зона для разработки, тестирования, staging и публикации проектов.

## Жёсткие границы
- Работа выполняется только в ветке `DEV/WORKSPACE-PORTFOLIO-2026-09-03`.
- Рабочие файлы проектов находятся только внутри `WORKSPACE/`.
- `main`, `FROZEN/*`, MMW-RESERW, MMW-ORDER и опубликованные оригиналы не являются рабочими источниками ФАБРИКИ.
- Workflow каждого проекта должен иметь собственный путь trigger, собственную concurrency-группу и не должен записывать код в другие проекты.

## Производственный цикл
DEV → TEST → STAGE → READY → RELEASE → ARCHIVE

## Проверки
Каждый переход должен иметь автоматические проверки структуры, HTML, ссылок/ресурсов и наличие стартового файла.

## Публикация
ФАБРИКА публикует только содержимое выбранного RELEASE/READY-пакета. Публикация не изменяет исходный код проекта и не выполняет push в main или frozen.

## Принцип восстановления
Каждый RELEASE — неизменяемый снимок. Любая новая работа начинается в DEV и не редактирует предыдущий RELEASE.
