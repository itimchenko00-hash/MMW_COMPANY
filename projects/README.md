# MMW-COMPANY / PROJECT PORTFOLIO

This directory is the canonical home of every MMW-COMPANY development product.

MMW-COMPANY is the parent Business Development Studio / Project Factory. Each project below is an independent product with its own concept, market, land, architecture, engineering, economics, capital structure, team, roadmap, risks, documents, sales/investment materials and decision gates.

## Portfolio

1. **ALADIN** — Residential / Development — `/aladin-v2`
2. **NEXUS WORK** — Commercial / Business Space — `/nexus` — FROZEN
3. **NEXUS LOGISTICS** — Logistics / Infrastructure — `/nexus-logistics`
4. **CARPATHIA ECO LODGE** — Hospitality / Tourism — `/carpathia-master`
5. **AGROHUB** — Agro / Processing — `/agrohub`
6. **ENERGY PARK** — Energy / Industrial — `/energy`

## Architecture

```text
MMW-COMPANY
│
├── company/                 # parent company
├── projects/                # all independent products
│   ├── ALADIN/
│   ├── NEXUS-WORK/
│   ├── NEXUS-LOGISTICS/
│   ├── CARPATHIA/
│   ├── AGROHUB/
│   └── ENERGY-PARK/
├── templates/               # reusable development standards
└── src/                     # common web/runtime layer
```

## Master standard

CONCEPT → PRODUCT → LOCATION → LAND → MASTERPLAN → MARKET → ARCHITECTURE → ENGINEERING → CAPEX → PRICE / REVENUE → FINANCIAL MODEL → OPERATING MODEL → CAPITAL / INVESTMENT → TEAM → ROADMAP → RISKS → DOCUMENTS → SALES / MARKETING → INVESTMENT MEMORANDUM → PRESENTATIONS → DATA ROOM → DECISION GATE.

## Rule

The projects are independent products. They share only the MMW-COMPANY development standard, governance, financial discipline, project gates and Data Room architecture.

MMW-ORDER remains a separate service and is not part of this repository.
