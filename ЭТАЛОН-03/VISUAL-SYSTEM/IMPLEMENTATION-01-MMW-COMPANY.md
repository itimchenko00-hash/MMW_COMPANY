# IMPLEMENTATION 01 — MMW-COMPANY HOME

## Objective
Transfer the locked **VISUAL MASTER 01 — MMW-COMPANY FACTORY** into the ETALON-03 MMW-COMPANY home page.

## Current baseline
`company/website/mmw-company-interactive-v11.html`

## Implementation sequence
1. Preserve page architecture and anchors.
2. Extract Factory visual tokens into the ETALON-03 visual layer.
3. Normalize typography, spacing, borders, radii, surfaces and accent states.
4. Preserve the Factory hero composition and information hierarchy.
5. Preserve the Factory system cards, portfolio cards, economics/model blocks, roadmap and contact treatment.
6. Consolidate repeated visual rules into reusable components/tokens where the existing runtime permits.
7. Keep all responsive behavior for desktop, tablet and mobile.
8. Keep technical SVG/diagram language consistent with Factory.
9. Verify that project-specific visual identities can later branch from the MMW master without copying project business content.

## Non-goals
- No change to the MMW-COMPANY information architecture.
- No restoration from ETALON-02.
- No modification of protected/conserved versions.
- No replacement of Factory visual DNA with a new design system.
- No presentation of conceptual project visuals as built/operational objects.

## Acceptance criterion
ETALON-03 MMW-COMPANY should be visually recognizable as the Factory MMW-COMPANY version while being implemented as the canonical ETALON-03 working version.
