# PROJECT COLOR SYSTEM 01 — MMW-COMPANY / ETALON-03

## Status
LOCKED VISUAL RULESET 01

Source visual language: MMW-COMPANY FACTORY / VISUAL MASTER 01.

Purpose: give each ETALON-03 project an individual color identity while preserving one shared MMW-COMPANY visual DNA.

## 01 / SHARED MMW BASE

All projects retain the same structural base:
- dark technical background
- graphite / neutral surfaces
- light primary typography
- restrained secondary typography
- thin technical borders and diagram lines
- compact data-oriented UI treatment
- project accent used selectively, never as a replacement for the MMW base

Shared semantic roles:
- `--mmw-bg`: primary dark background
- `--mmw-surface`: elevated graphite surface
- `--mmw-surface-2`: secondary surface
- `--mmw-text`: primary light text
- `--mmw-muted`: secondary text
- `--mmw-line`: technical border/grid
- `--project-primary`: main project accent
- `--project-secondary`: supporting accent
- `--project-soft`: low-opacity/background accent
- `--project-signal`: CTA, status or data signal

## 02 / PROJECT PALETTES

### ALADIN RESIDENCE
Character: residential / architectural / warm / natural.
- Primary: warm sand
- Secondary: terracotta
- Soft: warm beige
- Signal: restrained copper
Use for architectural diagrams, section labels, CTA states, key metrics and selected hero details.

### NEXUS WORK
Character: business / technology / urban / precise.
- Primary: cool blue
- Secondary: graphite-blue
- Soft: blue-grey
- Signal: electric blue
Use for workspace diagrams, business metrics, navigation states, data visualization and selected interactive accents.

### NEXUS LOGISTICS
Character: logistics / infrastructure / industrial / operational.
- Primary: industrial blue
- Secondary: steel grey
- Soft: blue-grey
- Signal: amber
Use amber only for operational signals, movement, priority, status and selected CTAs.

### AGROHUB
Character: agro / production / processing / natural systems.
- Primary: deep green
- Secondary: olive
- Soft: muted natural green
- Signal: agricultural yellow
Use for process diagrams, production flows, land/agro references, metrics and selected signals.

### ENERGY PARK
Character: energy / technology / infrastructure / high-performance.
- Primary: electric cyan
- Secondary: deep graphite-blue
- Soft: dark cyan tint
- Signal: energy yellow
Use cyan for technical networks and system diagrams; yellow for energy/status signals and high-priority data.

### CARPATHIA ECO LODGE
Character: nature / hospitality / mountains / ecology.
- Primary: forest green
- Secondary: conifer green
- Soft: mountain blue-green
- Signal: alpine blue
Use for landscape diagrams, experience maps, hospitality states, nature-related metrics and selected CTA accents.

## 03 / USAGE RATIO

The MMW base remains dominant.

Recommended visual balance:
- 70–85% shared neutral MMW system
- 10–20% project identity
- 3–10% high-intensity signal/accent

Do not turn an individual project into a fully colored theme. The project color is an identity layer inside the MMW technical environment.

## 04 / COMPONENT RULES

Project color may appear in:
- active navigation state
- project code / section number
- thin borders and technical lines
- SVG diagrams
- data visualization
- selected metrics
- CTA / interactive states
- hero detail or controlled gradient
- project card identifier on MMW-COMPANY home

Project color should NOT automatically fill:
- the whole page background
- all cards
- all typography
- large decorative surfaces
- every icon

## 05 / MMW HOME

MMW-COMPANY home keeps the neutral Factory palette as its canonical environment.

Project cards may use a restrained project-color identifier so the six projects are visually distinguishable without breaking the MMW master system.

## 06 / IMAGE LANGUAGE

Image treatment follows VISUAL MASTER 01.

For conceptual projects, imagery must be explicitly classified when relevant:
- CONCEPT RENDER
- 3D ARCHITECTURAL VISUALIZATION
- REFERENCE
- REAL PROJECT PHOTO
- DIAGRAM
- MASTERPLAN

Conceptual visualization must never be presented as a built or operational object.

## 07 / ACCESSIBILITY

Accent colors are secondary to text contrast. Primary text remains on the shared MMW neutral base. Bright project accents should be used for signals, borders, labels and graphics rather than long body-copy text.

## 08 / GOVERNANCE

This file defines the project-color layer only. It does not change business content, information architecture, protected/conserved versions, or technical project documentation.

Future implementation should use shared tokens/components with project-specific CSS variables or theme classes. Do not duplicate the MMW visual system per project.
