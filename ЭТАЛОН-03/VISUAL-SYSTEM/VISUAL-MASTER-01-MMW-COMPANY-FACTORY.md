# VISUAL MASTER 01 — MMW-COMPANY FACTORY

Status: FIXED / MASTER
Source: MMW-COMPANY Factory visual version
Target: ЭТАЛОН-03/MMW-COMPANY-WORK

## 1. Rule

The MMW-COMPANY Factory version is the authoritative visual reference for ETALON-03.
ETALON-03 must reproduce and technically improve this visual language without replacing its design DNA.

Visual chain:

FACTORY MMW-COMPANY → VISUAL MASTER 01 → ETALON-03 → project visual systems

## 2. Core visual DNA

- Dark deep-green background system.
- Warm gold accent for emphasis, actions and key values.
- White/soft-white primary typography.
- Muted green-gray secondary text.
- Thin green borders and technical separators.
- Rounded cards with restrained radius.
- Editorial / technical business-development aesthetic.
- High information density without visual clutter.
- Photography combined with technical SVG/diagram overlays.
- Strong uppercase micro-labels and numbered system sections.

## 3. Typography

Primary body: DM Sans.
Display/headings: Manrope.

Hierarchy:
- micro labels / eyebrow: uppercase, compact, tracked;
- H1: large Manrope, tight line-height, negative tracking;
- H2/H3: Manrope, strong hierarchy;
- body: DM Sans;
- metadata: DM Sans, muted and compact.

## 5. Layout system

- Maximum content width: 1180px.
- Desktop navigation: sticky, blurred dark surface, thin border.
- Hero: two-column composition on desktop; single-column on tablet/mobile.
- Sections separated by thin technical rules.
- Cards arranged through responsive grids.
- Primary CTA uses the Factory gold treatment.
- Secondary CTA uses transparent/dark treatment with technical border.

## 6. Signature components

NAV / LOGO / PRIMARY CTA / HERO / HERO VISUAL / STATS STRIP / SECTION HEADER / SYSTEM CARDS / PRODUCT CARDS / PORTFOLIO CARDS / TECHNICAL SVG OVERLAYS / ECONOMIC MODEL PANEL / ROADMAP / CONTACT / FOOTER.

## 7. Image treatment

Images are darkened and desaturated toward the MMW palette, with a dark gradient overlay. Technical SVG diagrams may sit above imagery. Images must support the content rather than act as decoration only.

For conceptual projects, imagery must be labelled according to the ETALON-03 asset policy: CONCEPT RENDER, 3D ARCHITECTURAL VISUALIZATION, REFERENCE, REAL PROJECT PHOTO, DIAGRAM or MASTERPLAN as applicable.

## 8. Responsive baseline

Desktop: full two-column hero and multi-column grids.
Tablet: hero collapses to one column; cards reduce to 2–3 columns.
Mobile: single-column cards, compact navigation, reduced hero height, stacked actions and readable section spacing.
