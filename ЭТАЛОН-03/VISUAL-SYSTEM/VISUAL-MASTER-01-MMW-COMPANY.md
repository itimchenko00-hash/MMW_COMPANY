# VISUAL MASTER 01 — MMW-COMPANY FACTORY

**Status:** LOCKED / reference source
**Version:** VISUAL MASTER 01
**Scope:** MMW-COMPANY visual language for ETALON-03

## Source of truth
The visual benchmark is the existing **MMW-COMPANY Factory** version represented by:

`company/website/mmw-company-interactive-v11.html`

The Factory visual system is the source reference. ETALON-03 develops from this benchmark; it does not replace it with a new visual identity.

## Locked visual DNA
- Dark deep-green interface
- Warm gold accent system
- Light neutral typography
- DM Sans for interface/body text
- Manrope for headings and display typography
- Sticky translucent navigation with thin borders
- Compact uppercase eyebrow labels
- Large editorial hero typography
- Rounded cards with restrained borders
- Gold primary actions and outlined secondary actions
- Architectural / business-system imagery with dark overlays
- Thin technical separators and structured grids
- Responsive desktop / tablet / mobile behavior
- Combination of photographic imagery and technical SVG-style diagrams
- Calm, premium, technical business-development character

## Transfer rule
`FACTORY → VISUAL MASTER 01 → ETALON-03 MMW-COMPANY → PROJECT VISUAL SYSTEMS`

Do not redesign the MMW-COMPANY visual language while performing this transfer.

## First implementation target
The first ETALON-03 implementation target is the MMW-COMPANY home page. Preserve the existing page architecture and content structure while transferring and consolidating the Factory visual system into a reusable visual layer.

## Component layer
The implementation should converge on reusable tokens/components for:
- navigation
- hero
- eyebrow labels
- headings
- CTA buttons
- statistic strip
- section headers
- cards
- visual cards / image overlays
- technical SVG diagrams
- panels and tables
- roadmap phases
- contact/form blocks
- footer
- responsive breakpoints

## Asset policy
Factory/reference imagery may be reused as a visual benchmark. Conceptual imagery must not be presented as a real completed project. Where project visuals are conceptual, label them appropriately (`CONCEPT RENDER`, `3D ARCHITECTURAL VISUALIZATION`, `REFERENCE`, `DIAGRAM`, etc.).

## Boundary
This file establishes the visual reference only. It does not authorize changes to protected/conserved versions, `main`, ETALON-02, or unrelated project branches.
